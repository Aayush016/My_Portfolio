# Static Portfolio Starter

This dependency-free portfolio is ready to open locally or deploy to any static host.

## Customize

1. In `index.html`, replace every bracketed placeholder such as `[NAME]`, `[ROLE]`, `[SKILL_SET]`, `[PROJECT_URL]`, and `[EMAIL]`.
2. Replace the two example projects with your own project links and short descriptions.
3. Point `mailto:[EMAIL]` and the professional profile links to real destinations.
4. Replace the remote font link if a completely offline presentation is required.

## Publish

Upload this folder to Netlify, GitHub Pages, Cloudflare Pages, or Vercel. No build command is required.

## Structure

- `index.html` — content, metadata, and semantic markup
- `profile.html` — profile links and contact details
- `styles.css` — responsive visual design
- `profile.css` and `home-links.css` — styles for the profile links
- `script.js` — accessible mobile navigation and current-year footer
